# Project notice

This repository contains the author's implementation, experiments, and documentation for an academic multi-task computer-vision project on PASCAL VOC2012.

## Dataset

PASCAL VOC2012 images and annotations are **not redistributed** in this repository. To reproduce the experiments, obtain the dataset from the official PASCAL VOC distribution and place it under `VOCdevkit/VOC2012/` (or set `VOC_ROOT`).

The project uses the 20 PASCAL VOC object categories and follows the official train/validation partitions described in the experiment notebook.

## Academic context

The work originated as a 2025-2026 Artificial Neural Networks and Deep Learning project at Hasselt University. The public repository separates the complete executed experiment from reusable source modules and concise technical documentation.

The archived academic report is preserved as submitted when it is included under `reports/`; course-provided materials and the raw dataset are not part of the repository.
